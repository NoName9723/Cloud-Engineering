# NEXORA — Cloud Engineering

Site vitrine multipage de démonstration autour du Cloud Engineering et du Platform Engineering.

## Pages
- `index.html` — accueil et présentation générale
- `expertise.html` — domaines d'expertise et méthode
- `solutions.html` — détail des prestations et livrables
- `architecture.html` — architecture de référence et onglets interactifs
- `technologies.html` — panorama des technologies
- `company.html` — approche et principes
- `lab.html` — mini-simulation interactive de capacité cloud
- `contact.html` — formulaire avec validation côté navigateur
- `404.html` — page d'erreur personnalisée

## Technologies
HTML5, CSS3, JavaScript natif et illustrations vectorielles SVG. Aucun framework ni étape de compilation n'est requis. Les images de réseau et d'exploitation cloud sont des schémas conceptuels conçus pour ce site ; les adresses IP sont des exemples.

## Cloud Lab
Simulation locale en cinq missions. Le joueur configure des instances, un cache et l'autoscaling, puis observe l'effet sur la capacité, la disponibilité simulée et le budget. Aucune ressource cloud réelle n'est créée et aucun fournisseur n'est appelé.

## Fonctionnalités
- Navigation multipage et menu responsive.
- Liens internes entre rubriques et sections.
- Onglets interactifs pour comparer des modèles d'architecture.
- Questions fréquentes repliables.
- Validation navigateur du formulaire de contact.
- Animations d'apparition respectant la préférence de réduction des animations.

## Publication
Le site est conçu pour GitHub Pages : dépôt public, branche `main`, dossier `/(root)`.

## Limites connues
Le formulaire de contact est uniquement front-end : aucune donnée n'est transmise ni stockée. Pour recevoir des demandes, connecter un service de formulaire ou une API backend. NEXORA est une marque fictive utilisée pour la démonstration ; les contenus techniques illustrent des pratiques générales et ne constituent pas des références clients.
